Power Query (M) code

Place your Power Query (.pq) files here. Naming convention:

  <query_name>[_snapshot_YYYYMMDD].pq

Suggested metadata at top of each file (plain text header):
- Query name
- Workbook/location
- Author
- Date
- Purpose / role
- Related inventory entry: docs/current_state_transformation_inventory.md (search by query name)

Link each .pq to a sample CSV in test_data/expected/ named <query_name>_sample.csv.
